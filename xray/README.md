# Xray 家族包（v2rayNG + V2rayN + FoXray）

## 这是什么

这一家用 Xray/V2Ray 内核，靠「路由规则」分流。**先把最重要的话说前面**：这一家只能做到「哪些网站走代理、哪些直连、哪些拦截」这三件事，**做不到 FlClash 那种按服务自动分地区**（比如 AI 自动走美国节点）——因为 v2rayNG/V2rayN 的路由只能把流量交给「当前选中的那个节点」，没法给每个服务各指一个地区的节点。这一份包是这一家机制内能做到的最完整版本，差距在下面写清，不假装等效。

- **文件**：
  - `v2rayNG-V2rayN-routing.json` —— **APP 导入版**（v2rayNG 安卓、V2rayN 电脑通用格式），主要用这个。
  - `v2rayNG-custom-rules.txt` —— 旧版 v2rayNG「自定义规则」三栏粘贴版（代理/直连/拦截分开列）。
  - `xray-routing.json` —— Xray 内核原生路由段，给自己拼完整配置的人用（一般用不上）。拼的时候注意：完整配置的 outbounds 里要有 `proxy` / `direct` / `block` 三个出口（tag 必须一字不差），路由段最后一条兜底规则带了 `network: tcp,udp`——这是内核的硬要求，删了会报「rule has no effective fields」导致整个配置起不来。
- **能用在哪些 APP**：**v2rayNG**（安卓）、**V2rayN**（电脑 Windows/Mac/Linux）、**FoXray**（苹果，走 Xray 内核，导入方式近似，仅供参考）。
- **仓库链接**：
  - `https://gcore.jsdelivr.net/gh/YiMing918/proxy-app-rules@main/xray/v2rayNG-V2rayN-routing.json`
  - `https://gcore.jsdelivr.net/gh/YiMing918/proxy-app-rules@main/xray/v2rayNG-custom-rules.txt`
  - `https://gcore.jsdelivr.net/gh/YiMing918/proxy-app-rules@main/xray/xray-routing.json`
- **有什么用**：
  - 分流：AI、YouTube、流媒体、社交等该走代理的走代理；国内、哔哩、苹果、微软、远控、测速直连；广告拦掉。
  - 去广告：用 geosite 的广告分类（category-ads-all）在路由层直接拦，不用装证书。
  - 网速优化：嗅探、Mux 连接复用这类在 APP 设置里开（下面写了在哪开），路由文件本身只管分流。

## 怎么用（按 APP 分开看）

### v2rayNG（安卓）
1. **先导入订阅**：主页右上角「+」→「从剪贴板导入」或扫码，先把你的订阅/节点加进来，并**点选一个节点**作为当前节点（所有走代理的服务都走它）。
2. **导入路由**：「设置」→「路由设置」→ 右上角菜单「从剪贴板导入规则集」→ 把 `v2rayNG-V2rayN-routing.json` 的内容整段复制粘贴进去。
   - 老版本没有「路由设置」时：用 `v2rayNG-custom-rules.txt`，在「设置 → 自定义规则」里把「代理/直连/拦截」三段分别粘到对应页签。
3. **启用路由**：还是在「路由设置」里，**把刚导入的这套规则点选为当前规则集** —— 导入了不选不生效。
4. **开嗅探**：「设置」里把「开启流量嗅探」打开（网速优化，见下节）。
5. 回主页打开连接开关。
6. 验证：打开 ChatGPT（走代理能开）、百度（直连秒开）、开屏广告被拦。
7. 更新：geosite 数据库在「设置 → 更新订阅与规则」类入口里更新（不同版本叫法略有差异，找「更新 geosite/geoip」）；规则集本身有新版时重新粘贴导入。

### V2rayN（电脑）
1. **先导入订阅**：「订阅分组」→「订阅分组设置」加你的订阅链接，更新后**双击选一个节点**设为当前。
2. **导入路由**：「设置」→「路由设置」→「添加」或「导入」→ 选 `v2rayNG-V2rayN-routing.json`（V2rayN 与 v2rayNG 新版的规则集格式通用）。
3. **启用路由**：在路由设置列表里**把这套规则设为当前启用** —— 不启用不生效。
4. **开嗅探/Mux**：「设置 → 参数设置」里确认「开启流量嗅探」打开；Mux 在节点/核心设置里按需开（见下节说明）。
5. 验证同上。
6. 更新：「帮助/设置」里的「更新 geo 文件」保持 geosite 最新；规则集重新导入。

### FoXray（苹果）
导入自定义配置时把 `xray-routing.json` 的路由段并入完整配置使用，步骤随版本差异较大，这里只给文件，不保证一键导入。

### 要不要装证书（MITM）
这一家不用装证书：去广告是路由层按域名分类拦的。

### 常见问题
- **导入失败**：JSON 被改坏（少括号/引号）最常见，原样粘贴别手改；旧版 v2rayNG 不认新版规则集格式时，改用三栏粘贴版 txt。
- **规则不生效**：先查规则集有没有被「点选为当前」；再查是不是开了「全局代理」模式（全局模式不走路由分流）。
- **某个服务想换地区**：这一家做不到按服务换地区——只能把当前节点换成那个地区的节点，所有走代理的服务会一起换。要按服务分地区，请用 mihomo 家族或小火箭/Loon/QX。
- **节点不进组**：这一家没有「组」的概念，不存在这个问题；节点只有「当前选中」一个。
- **某个网站打不开**：在路由里把它的域名从拦截/代理段挪到直连段试，或临时切全局直连验证是不是被广告分类误拦。

## 两条硬规矩在这一家是什么样（如实说）

**规矩一：默认地区没节点要顺位兜底——这一家没有「组」，谈不上自动顺位。**
v2rayNG/V2rayN 里所有走代理的服务共用你当前选中的那一个节点，没有用途组、没有地区组，自然也没有兜底链。节点坏了或想换地区，**你要手动做的事**：在节点列表里重新点选一个节点（APP 里先测一遍延迟再挑低的）。这是这一家机制的全部，没有任何配置能把它变成自动的——想要自动顺位，用 mihomo 家族或小火箭/Loon/圈 X。

**规矩二：家宽节点只许手动，绝不自动——这一家天然就是这样，但也没有专门的家宽组。**
这一家压根没有任何自动组，所以家宽节点不可能被「自动用上」，规矩的精神天然满足；但它也没有「🏠 家宽节点」这种专门分组，家宽节点就是节点列表里一个普通节点，你要用时手动点选它、不用时别选就行。想要家宽单独成组管理，还是得用其他家族。

## 网速优化做了什么

路由文件管不了测速和 DNS，这一家的网速优化在 **APP 设置**里，导入后顺手开好：

- **流量嗅探（sniffing）**：v2rayNG「设置 → 开启流量嗅探」、V2rayN「参数设置 → 开启流量嗅探」。开了之后，直接连 IP 的流量也能认出域名，分流才命中得准——这是这一家最重要的一项，不开分流会漏很多。
- **Mux 连接复用**：V2rayN 节点设置/核心设置里的「Mux 多路复用」，v2rayNG 新版在设置里也有。把多个小连接挤进一条隧道，高延迟线路上刷网页更跟手；但看视频/下载大文件时可能略降速，不舒服就关掉。默认建议：日常刷网页开、下载关。
- **测速挑节点**：这一家没有自动测速组，靠 APP 的「测试真延迟」给节点排序，手动挑延迟低的当当前节点；**注意别频繁全量测速**，和 FlClash 版省额度的思路一样，测速也是要走节点流量的。
- **geosite/geoip 保持更新**：分类库新，国内/国外分得才准，误判少了自然少绕路。更新入口见上文各 APP 步骤。
- **DNS**：v2rayNG/V2rayN 的 DNS 设置里建议填国内加密 DNS（如阿里 DoH），防污染；这一项各版本位置不一，在设置里搜「DNS」即可，本包不写死以免和版本对不上。自己拼完整配置的人，可参考下面这段 DNS 段示例（仅示例，`xray-routing.json` 本身仍不含 DNS 段——只给示例，不改路由文件）：

  ```json
  "dns": {
    "servers": [
      { "address": "https://dns.alidns.com/dns-query", "domains": ["geosite:cn", "geosite:private"] },
      { "address": "https://doh.pub/dns-query", "domains": ["geosite:cn", "geosite:private"] },
      { "address": "https://dns.cloudflare.com/dns-query", "domains": ["geosite:geolocation-!cn"] },
      { "address": "https://dns.google/dns-query", "domains": ["geosite:geolocation-!cn"] }
    ],
    "queryStrategy": "UseIPv4"
  }
  ```

  口径与 mihomo 家族一致：国内域名走阿里 DoH（备用腾讯 DoH），国外域名走 Cloudflare DoH（备用 Google DoH），只解析 IPv4；拼的时候把这段与路由段并排放在完整配置的顶层即可。

## 规则来源

| 叫什么 | 干什么用 | 要装证书吗 | 来源 |
|---|---|---|---|
| v2fly geosite/geoip 官方分类库 | 全部服务分类（openai、youtube、category-ads-all 广告分类等）和国内外 IP 判断，由 APP 内置/更新 | 不用 | https://github.com/v2fly/domain-list-community 与 https://github.com/v2fly/geoip |

这一家没有插件/重写生态，**没有插件清单**；去广告就靠 geosite 的广告分类，如实说明。规则文件的写法对照的是 v2rayNG 官方仓库自带的预置路由文件格式（2dust/v2rayNG 仓库 assets 里的 custom_routing_white）。
