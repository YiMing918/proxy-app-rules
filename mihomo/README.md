# mihomo / Clash 家族包

## 这是什么

这一家都用同一个内核（mihomo，原 Clash.Meta），所以一份文件全家通用：

- **文件 1**：`FlClash_override.js` —— 站长 FlClash 覆写脚本（v3.5，已落实两条硬规矩），**只有 FlClash 能直接用**（别的 APP 不吃 JS 覆写）。
- **文件 2**：`mihomo-universal.yaml` —— 把 v3.5 的全部分组、规则、DNS、网速设置翻译成的通用配置，**下面这些 APP 都能用**：
  - **FlClash**（安卓/电脑）：优先用文件 1；也可以用文件 2。
  - **Clash Verge Rev**（电脑 Windows/Mac/Linux）
  - **Mihomo Party**（电脑 Windows/Mac/Linux）
  - **ClashMeta**（安卓，ClashMeta for Android）
  - **Stash**（苹果，付费）
  - **OpenClash**（路由器，OpenWrt）
- **仓库链接**：
  - `https://gcore.jsdelivr.net/gh/YiMing918/proxy-app-rules@main/mihomo/FlClash_override.js`
  - `https://gcore.jsdelivr.net/gh/YiMing918/proxy-app-rules@main/mihomo/mihomo-universal.yaml`
- **有什么用**：
  - 分流：不同网站/App 自动走不同地区的节点（AI 走美国、YouTube 走香港、国内直连）。
  - 去广告：ACL4SSR 维护的广告规则集（和 FlClash 版同源）+ 秋风去广告规则集，按域名拦，不用装证书。
  - 网速优化：和 FlClash 版完全同一套（加密 DNS 分流解析、fake-ip、嗅探、TCP 并发等，细目见下面）。

## 怎么用（按 APP 分开看）

### 通用第一步：把配置里的订阅链接换成你的
`mihomo-universal.yaml` 顶部 `proxy-providers` 里的 `sub` 是占位链接（`https://example.com/把这里换成你的订阅链接`）。先用记事本/编辑器把这行换成你自己的订阅链接再导入。不换的话一个节点都没有。

### FlClash（安卓/电脑）—— 用 JS 覆写（推荐）
1. 导入订阅：主页「配置」→ 右下角「+」→「从 URL 导入」粘贴订阅链接。
2. 导入覆写：主页「工具」→「覆写」→「+」→ 选 JS 文件导入 `FlClash_override.js`（或粘贴它的链接）。
3. **启用覆写**：回到「配置」页，点你的订阅配置右上角「⋮」→「覆写」→ 勾选刚导入的这份 JS —— **不勾选不生效**。
4. 回到主页打开总开关即可。验证：进「代理组」能看到 🤖 AI服务等分组、默认线路和下表一致。
5. 更新：订阅在配置页下拉刷新；覆写脚本本身不会自动更新，有新版时重新导入 JS 文件再勾选一次。

### Clash Verge Rev（电脑）—— 用 YAML
1. 左侧「订阅」→ 顶部输入框粘贴**你自己的订阅链接**先导入一份订阅（保证有节点），或直接导入 `mihomo-universal.yaml`（已换好订阅链接的话）。
2. 导入 YAML：「订阅」页 →「新建」→ 类型选 Local（本地）→ 选 `mihomo-universal.yaml` 文件。
3. **点一下这份配置的卡片把它设为当前配置** —— 不点选不生效。
4. 左侧「代理」页能看到全部分组；打开「Tun 模式」开关（设置页）可以让全电脑流量都走分流。
5. 更新：订阅页对卡片点刷新图标；本地文件改了要重新导入。

### Mihomo Party（电脑）—— 用 YAML
1. 左侧「订阅」→ 右上角「+」→ 可以粘贴订阅链接先加节点。
2. 再用「+」→「导入本地文件」选 `mihomo-universal.yaml`。
3. **在订阅列表里点这份配置切换为当前配置** —— 不切换不生效。
4. 「代理组」页确认分组和默认线路；需要全局接管时打开 TUN。
5. 更新：订阅卡片上点更新；本地配置重新导入。

### ClashMeta（安卓）—— 用 YAML
1. 主页「配置」→ 右下角「+」→「从文件导入」选 `mihomo-universal.yaml`（先换好订阅链接）。
2. **在配置列表里点选这份配置** —— 不点选不生效。
3. 回主页打开开关；点「代理」能看到分组。
4. 注意：ClashMeta 维护较少，新版 mihomo 的个别字段它可能不认；能导入能用即可，报错时优先换 FlClash。
5. 更新：配置列表里对这份配置点「更新」（URL 导入时）或重新导入文件。

### Stash（苹果）—— 用 YAML
1. 主页「设置」→「配置」→「添加配置」→ 选文件/链接导入 `mihomo-universal.yaml`（先换好订阅链接）。
2. **在配置列表里点选它设为当前配置** —— 不点选不生效。
3. 回主页打开开关，在「策略组」里确认默认线路。
4. Stash 对 YAML 的支持最接近 mihomo 本体，本包字段基本都能认。
5. 更新：配置页对它点更新（链接导入时）。

### OpenClash（路由器）—— 用 YAML
1. 电脑上先把 `mihomo-universal.yaml` 里的订阅链接换好。
2. 路由器后台进 OpenClash →「配置管理」→ 上传这份 YAML → **在配置列表里点「启用」这份配置** —— 不启用不生效。
3. 「运行状态」显示运行中后，全家的设备自动走分流，不用每台设备装 APP。
4. 更新：重新上传覆盖，或在配置管理里对订阅部分单独更新。
5. 注意：OpenClash 自带的覆写/规则设置不要再叠加，避免和这份配置打架。

### 要不要装证书（MITM）
这一家全都不用装证书：分流和去广告都是按域名/规则集拦的，不解密流量。

### 怎么验证已经生效
1. 对应 APP 的代理组页面里能看到 🤖 AI服务、📺 YouTube 等分组，默认线路和下表一致。
2. 打开 ChatGPT 能用（走美国组）、打开国内网站速度正常（直连）。
3. 开屏广告多的 App 里广告被跳过；或在 APP 的连接日志里看到广告域名走了「🛑 广告拦截」。

### 常见问题
- **导入失败**：多半是 YAML 被记事本改坏了格式（缩进/全角符号）。别手动改内容，只改那一行订阅链接；还不行就重新下载原文件。
- **规则不生效**：先查配置有没有被设为「当前配置」；再查模式是不是「规则」模式（全局模式会绕过分流）。
- **一个节点都没有**：订阅链接没换或写错，检查 `proxy-providers` 那一行。
- **节点不进组（地区组空的）**：分组按节点名地区词认人（香港/🇭🇰/HK 都认）；节点名不带地区信息的，去「👋 手动选择」直接挑。

## 两条硬规矩（全套包统一，写在分组表这里）

**规矩一：默认地区没节点，会自动顺位，不会让组空着。**
每个用途组的第一顺位只是「默认」，不是唯一。比如 YouTube 默认香港，但你的订阅里一个香港节点都没有时，这个组不会失效——YAML 版里它默认选的是「📺 YouTube·顺位」兜底链组（fallback 组），顺序是：香港 → 日本 → 新加坡 → 美国 → 台湾 → 韩国 → 其他各地区 → ♻️ 自动选择（压尾）。链上哪个地区有节点就用哪个，只要订阅里还有任何节点，这个组就有得用。其他用途组同理：先走自己的偏好地区（AI 美国打头、流媒体 新加坡→美国），再按 新加坡/美国/台湾/日本/香港/韩国 补位，最后压自动选择。
**但这只是默认行为，没有锁死**：每个用途组仍是手动可选组，所有地区组都列全了，随时能自己改选任何地区组或具体节点——和 v3.5 的形态一样（select 组带默认第一顺位），没有做成不可改的纯自动组。

**规矩二：家宽节点只许手动，绝不自动。**
名字里带「家宽 / 住宅 / 家庭宽带 / Residential」的节点，只出现在「🏠 家宽节点」这一个组里（纯手动选）。所有自动组——♻️ 自动选择、🛡️ 故障转移、⚖️ 负载均衡、每一个地区组——都把它们剔干净了，连「👋 手动选择」里都不放（故意的，不是漏了）。
原因：免费家宽上一秒能用、下一秒超时，太不稳定，混进自动组会把测速和自动切换全带乱。需要家宽时，自己去「🏠 家宽节点」里点开用。
**要说清的一点**：同文件夹里的 JS 覆写脚本已升 v3.5、同样照办这一条——家宽只在「🏠 家宽节点」和「👋 手动选择」两个纯手动组里出现（YAML 版只放 🏠 一个，是两边各自的手动入口安排）；所有自动组都剔干净这一点，两边完全一致。

## 网速优化做了什么（与 FlClash 版同一套）

- **DNS 分开解析**：国外域名走 Cloudflare + Google 的加密 DNS（DoH），国内域名走阿里 + 腾讯的加密 DNS——解析又快又防污染，CDN 还能就近定位。
- **fake-ip 模式**：域名先给假 IP、连接时才真解析，省掉大量解析等待；微软检测、游戏联机等域名在排除名单里返回真实 IP，不会被弄坏。
- **嗅探打开**（sniffer）：App 直接连 IP 时也能认出域名，分流命中更准。
- **TCP 并发连接**（tcp-concurrent）：同一个域名多个 IP 时同时连，哪个先通走哪个，连通更快。
- **测速容差 50 毫秒 + 懒测速 + 600 秒间隔**：不频繁跳线、不烧额度（站长定死的节奏）。

## 与 FlClash 版的差别

- 本家族就是源头，策略一致，手动入口安排有差异；差别只在形式：FlClash 用 JS 覆写（导入订阅后运行时生成），YAML 版是把结果写死成配置文件。（版本号：以实际 JS 覆写脚本 v3.5 为准；YAML 文件头注释原写“由 v3.4 移植”，已同步更正为 v3.5。）
- YAML 版里订阅是一个 `proxy-providers` 入口：**多条订阅**的站长把 YAML 里那段按注释再复制几份即可（FlClash JS 版是给每个订阅自动套）。
- ClashMeta 年久失修，个别新字段可能不认（见上文）；Stash/OpenClash 无此问题。
