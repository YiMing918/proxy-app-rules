# 代理客户端规则包 · 总索引

这是一整套「照着 FlClash 覆写脚本 v3.4 移植」的分流规则包：同一套习惯（哪个网站走哪个地区、广告拦掉、测速不烧额度），做成了各个代理 APP 能直接导入的样子。**先按你的设备找平台，再在平台里找你用的 APP 名字**，每个 APP 一节，写清了文件是哪个、有什么用、分组默认走哪。

> ⚠️ **关于插件/模块/重写的提醒（重要）**：包里提到的插件、模块、重写，都是**别人写的代码**，装上等于让别人的程序在你的代理里干活。本包只收全网公认、还在长期维护的来源（blackmatrix7、秋风去广告 AWAvenue、KOP-XIAO、Orz-3、ACL4SSR、SagerNet、v2fly 这些），每一项都在对应 APP 的文件夹说明里写了来源链接。**千万别乱装来路不明的插件/模块**——轻则规则失效，重则流量被动手脚。要装就只从本包写的这些链接拿。

> 📌 链接说明：下面每个 APP 的「仓库链接」都是正式链接，走 jsDelivr 加速，国内直连就能拉，永远指向最新版。也可以把文件下到本地再导入，方法看每个文件夹的 README。

## 一共覆盖了哪些 APP

**做了的（18 个）**：
- 苹果：Shadowrocket（小火箭）、Loon、Quantumult X（圈 X）、Surge、Stash、Streisand、FoXray
- 安卓：FlClash、ClashMeta、Surfboard、sing-box 官方端（SFA）、Karing、Hiddify、v2rayNG
- 电脑：Clash Verge Rev、Mihomo Party、V2rayN（另有 FlClash/Surge/Karing/Hiddify 的电脑版，共用同一份文件，见各节）
- 路由器：OpenClash

**跳过的（附原因）**：
- 老版 Clash for Android（Kr328 那个）：早已停更、仓库都没了，它的活由 ClashMeta/FlClash 接了，不用做。
- nekoray：项目已归档停更，不做。
- 其余小众/停更客户端：没人维护的就不往里凑了。
