# sing-box 家族包

## 这是什么

这一家都用 sing-box 内核，一份 JSON 配置通用：

- **文件**：`sing-box-config.json` —— 完整配置，含分流规则（远程规则集）、地区分组、去广告、DNS 与网速优化。
- **能用在哪些 APP**：
  - **SFA / sing-box 官方端**（安卓 SFA、苹果 SFI、各平台命令行版）
  - **Karing**（安卓/苹果/电脑，全平台）
  - **Hiddify**（安卓/苹果/电脑，全平台）
  - **Streisand**（苹果）
- **仓库链接**：`https://gcore.jsdelivr.net/gh/YiMing918/proxy-app-rules@main/proxy_clients_rules/sing-box/sing-box-config.json`
- **有什么用**：
  - 分流：不同网站/App 自动走不同地区的出口（AI 走美国、YouTube 走香港、国内直连）。
  - 去广告：广告域名/规则集直接拒绝连接，不用装证书。
  - 网速优化：加密 DNS + fake-ip、嗅探、测速参数调稳（细目见下面）。

## ⚠️ 先看这一条（和别的家族不一样的地方）
sing-box **不会按节点名字自动分地区组**，这是它内核的机制，全家都一样。所以这份配置里 9 个地区组（香港/台湾/日本/韩国/新加坡/美国/英国/德国/其他）各放了**一个占位示例节点**，你必须：
1. 把每个地区组里的占位节点换成你自己订阅里对应地区的**真实节点**（改 JSON 里那个节点的服务器/端口/协议参数），或者
2. 更省事：先在 APP 里正常导入你的订阅，再把这份配置当「规则模板」对照着改。
不换的话，分组是空架子，连不出去。**这是 sing-box 家族的硬限制，不是配置写错了。**

## 怎么用（按 APP 分开看）

### SFA / sing-box 官方端（安卓/苹果）
1. 导入订阅（可选，为了拿真实节点参数）：主页「配置」→「+」→ 从 URL 导入你的订阅。
2. 导入本配置：把 `sing-box-config.json` 按上面说明换好节点后，「配置」→「+」→ 从文件导入。
3. **在配置列表里点选这份配置** —— 不点选不生效；然后回主页打开开关。
4. 验证：主页能看到各分组出口；打开 ChatGPT/YouTube 正常。
5. 更新：远程规则集 sing-box 会自己缓存更新；配置本身重新导入。

### Karing（全平台）
1. 主页「+」→「从剪贴板/文件导入」选 `sing-box-config.json`（换好节点后）。
2. **在配置列表里点选它**并回主页打开开关 —— 不点选不生效。
3. Karing 里也能直接加订阅拿节点，再对照本配置改出口分组。
4. 更新：配置页对它点更新/重新导入。

### Hiddify（全平台）
1. 主页「+ 新配置」→「从文件导入」选 `sing-box-config.json`（换好节点后）。
2. **点这份配置卡片设为当前**，回主页点大按钮连接 —— 不设为当前不生效。
3. 注意：Hiddify 有自己的「服务分流」简化设置，和本配置的规则同时存在时以本配置为准，别两边同时改。
4. 更新：重新导入覆盖。

### Streisand（苹果）
1. 主页「+」→「从文件导入」选 `sing-box-config.json`（换好节点后）。
2. **在列表里点选这份配置**，回主页打开开关 —— 不点选不生效。
3. 更新：重新导入。

### 要不要装证书（MITM）
这一家不用装证书：分流和去广告都是按域名/规则拦的。

### 怎么验证已经生效
1. APP 里能看到「🤖 AI服务」等分组出口，里面是你换进去的真实节点。
2. 打开 ChatGPT 能用、YouTube 能播、国内网站直连速度正常。
3. 开屏广告多的 App 里广告请求被拒（连接日志里能看到 reject）。

### 常见问题
- **导入失败**：JSON 格式被改坏最常见。用编辑器改节点时别动括号和引号；改完可以先过一遍 JSON 校验再导入。
- **连不出去/分组是空的**：占位节点没换成真实节点（见顶部警告）。
- **规则不生效**：先查配置有没有被设为当前；Hiddify 还要查它自带的分流设置有没有在抢。
- **某个网站打不开**：广告规则误拦时，把对应服务的规则在 JSON 里临时去掉，或把广告那条规则的出口改成 direct 试。

**本家族的出入（如实说）**：
- **地区组只有 9 个**（港/台/日/韩/新/美/英/德/其他），且每组要手动放真实节点（见顶部警告）；FlClash 版的 21 地区自动分组在这里做不到。
- **FCM 推送**：sing-box 没有「故障转移」这种出口类型，本包用自动测速组代替——它也会在节点坏掉后重新测速换线，效果接近，但不是连接失败立刻顺延那种机制。
- **广告没有可切换的分组**：sing-box 的广告拦截是写死在路由里的「拒绝」动作，没有 FlClash 版那种能一键改成直连的「🛑 广告拦截」分组；被误拦时要改 JSON。
- **低倍率/高倍率/优选IP 组没有**：因为没法按节点名筛人。家宽组有（见下面规矩二）。
- 自动测速组参数照 FlClash 版：间隔 600 秒、容差 50 毫秒（**不要改小间隔**，省额度设计）。

## 两条硬规矩（全套包统一；这一家只能做到一半，如实说）

**规矩一：默认地区没节点要顺位兜底——这一家做不到「真自动」，要手动顺一位。**
别的家族靠兜底链组自动顺位；sing-box 的选择器（selector）不会自动跳过「没放节点」的组。所以本包的做法是：每个用途组的可选项已经**按顺位链的顺序排好**（先偏好地区，再 新加坡/美国/台湾/日本/香港/韩国 补位，…，最后是 ♻️ 自动选择）。如果你默认的那个地区组里没放节点（或放的节点全坏了），**你要手动做的事**：点开这个用途组，把它切到链上的下一个地区组，就这么一下。实在懒得逐个切，切到「♻️ 自动选择」永远有得用（那里放了你全部的普通节点）。这是 sing-box 机制的上限，不是配置偷懒。
手动可选这一点是满格的：用途组本来就是选择器，任何时候都能改选。

**规矩二：家宽节点只许手动，绝不自动——这一家照办。**
配置里有专门的「🏠 家宽节点」组（纯手动选择），家宽占位节点只放在这里，**任何自动测速组（♻️ 自动选择、各地区自动组）里都没有它**。你换真实节点时也照此办理：家宽节点只往「🏠 家宽节点」组里放，别放进任何带「自动」的组。
原因：免费家宽上一秒能用、下一秒超时，太不稳定，混进自动组会把测速和自动切换全带乱。需要家宽时，自己点开「🏠 家宽节点」用。
（注：FlClash v3.4 原稿里家宽是留在各组当额外入口的；这一条是站长后来定的新规矩，移植版以新规矩为准。）

## 网速优化做了什么

- **DNS 新格式 + 加密解析**：国外走 Cloudflare DoH、国内走阿里 DoH，按域名分开解析，又快又防污染、CDN 就近。
- **fake-ip 开启**：先给假 IP 后解析，省解析等待；fake-ip 结果会存盘缓存（store_fakeip），重启不丢。
- **嗅探开启**（route 第一动作就是 sniff）：App 直接连 IP 时也认得出域名，分流命中准；DNS 流量自动劫持回本机解析（hijack-dns），防 App 用自带 DNS 绕过。
- **测速容差 50 毫秒 + 间隔 600 秒**：不频繁跳线、不烧额度，和 FlClash 版一致。
- **规则集用二进制格式（.srs）+ 国内镜像优先**：规则文件更小、加载更快，拉不到镜像再走 GitHub 原址。
- **只解析 IPv4**（ipv4_only）：和 FlClash 版一致，避开 IPv6 绕路。
- **连接与日志做了减负**：关掉没必要的详细日志，路由器/手机上跑着更轻。
