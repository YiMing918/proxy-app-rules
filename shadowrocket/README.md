# Shadowrocket（小火箭）包

## 这是什么

- **哪个 APP**：Shadowrocket，俗称「小火箭」，苹果手机/平板上的代理工具（App Store 付费下载）。
- **文件**：`Shadowrocket.conf` —— 一份完整配置，导入后自带全套分流分组、去广告规则和网速优化设置。
- **仓库链接**：`https://gcore.jsdelivr.net/gh/YiMing918/proxy-app-rules@main/shadowrocket/Shadowrocket.conf`
- **有什么用**：
  - 分流：不同网站/App 自动走不同地区的节点（比如 AI 走美国、YouTube 走香港、国内网站直连），不用手动切来切去。
  - 去广告：拦掉常见广告域名和 App 开屏/内嵌广告的请求，不用装证书就能生效。
  - 网速优化：解析更快、防污染、连接更稳（具体做了什么见下面「网速优化做了什么」）。

## 怎么用（一步一步）

### 1. 先导入你的节点订阅
1. 打开小火箭，点右上角「+」。
2. 类型选「Subscribe（订阅）」，把你的订阅链接粘进去，保存。
3. 回到首页，等节点列表刷出来，能看到一堆节点名字就对了。

### 2. 导入这份配置
1. 把 `Shadowrocket.conf` 放到能打开的地方（网盘、文件 App、或将来仓库的链接）。
2. 小火箭底部点「配置」→ 右上角「+」→ 选文件/粘贴链接导入。
3. 导入后在配置列表里**点一下这份配置**，让它前面出现 ✔️ —— **导入了不点选等于没生效**，这一步最容易漏。

### 3. 选中分组（让默认线路生效）
1. 回到首页，下拉或点「代理分组」区域。
2. 找到「🚀 节点选择」，确认它选的是「♻️ 自动选择」；各个用途分组（🤖 AI服务、📺 YouTube 等）已经按下面表格预设好默认地区，不用动。
3. 想临时换线路，点对应分组改选即可，改完即生效。

### 4. 要不要装证书（MITM）
- **本配置不用装证书**：分流和去广告都是按域名拦的，不解密你的流量。
- 只有你想再装下面「可选模块」里那种**改 App 内容**的重写模块时，才需要装：配置页 → 点当前配置后面的 ⓘ →「HTTPS 解密」→ 生成新的 CA 证书 → 安装 → 再去 iOS「设置 → 通用 → 关于本机 → 证书信任设置」里把小火箭的证书打开信任 → 回小火箭把「HTTPS 解密」开关打开。不装也不影响本包其他功能。

### 5. 怎么验证已经生效
1. 首页点「连通性测试」，节点能测出延迟。
2. 打开一个国内网站（如百度）和一个国外网站（如 YouTube），都正常打开。
3. 在首页「代理分组」里看「🤖 AI服务」，里面默认勾选的应该是「🇺🇸 美国」组；打开 ChatGPT 能正常用，说明 AI 分流生效。
4. 打开一个平时开屏广告多的 App，开屏广告被跳过/变短，说明去广告在工作（也可以在小火箭的「数据」→ 请求记录里看到 REJECT 记录）。

### 6. 以后怎么更新
- 配置本身：在「配置」页长按/点这份配置的「更新」即可重新拉取（用链接导入时）。
- 里面的去广告规则集是远程引用的，小火箭会定期自己更新，不用你管。
- 分组默认值想改：在首页分组里直接改选，改的是你的选择，不会动配置文件。

### 7. 常见问题
- **导入失败**：多半是文件没下载完整或链接打不开。换个方式（先下载文件再从「文件」导入）再试。
- **规则不生效**：先查第 2 步——配置有没有被点选（✔️ 在不在）；再查首页顶部是不是选了「全局代理/全局直连」模式，要选「配置」模式。
- **节点不进组（某个地区组是空的）**：分组是按节点名字里的地区词认人的（香港/🇭🇰/HK 都认）。你的订阅节点名如果完全不带地区信息（如只有编号），就认不出来——这种情况去「👋 手动选择」里直接挑节点用，或找订阅方换带地区名的节点。
- **某个网站打不开**：可能被去广告误拦。在「🛑 广告拦截」分组里临时改成 DIRECT 试试，能打开就是被误拦了。

## 两条硬规矩（全套包统一，写在分组表这里）

**规矩一：默认地区没节点，会自动顺位，不会让组空着。**
每个用途组的第一顺位只是「默认」，不是唯一。比如 YouTube 默认香港，但你的订阅里一个香港节点都没有时，这个组不会失效——它默认选的是「📺 YouTube·顺位」兜底链组，顺序是：香港 → 日本 → 新加坡 → 美国 → 台湾 → 韩国 → 其他各地区 → ♻️ 自动选择（压尾）。链上哪个地区有节点就用哪个，只要订阅里还有任何节点，这个组就有得用。其他用途组的链同理：先走它自己的偏好地区（如 AI 是美国打头、流媒体是新加坡→美国），再按 新加坡/美国/台湾/日本/香港/韩国 补位，最后压自动选择。
**但这只是默认行为，没有锁死**：点开任何用途组，里面所有地区组都列全了，你随时能自己改选任何一个地区组，或者去「👋 手动选择」点具体节点，改完立即生效。

**规矩二：家宽节点只许手动，绝不自动。**
名字里带「家宽 / 住宅 / 家庭宽带 / Residential」的节点，只出现在「🏠 家宽节点」这一个组里（纯手动选）。所有自动组——♻️ 自动选择、🛡️ 故障转移、⚖️ 负载均衡、每一个地区组——都把它们剔干净了，连「👋 手动选择」里都不放（故意的，不是漏了）。
原因：免费家宽上一秒能用、下一秒超时，太不稳定，混进自动组会把测速和自动切换全带乱。需要家宽时，自己去「🏠 家宽节点」里点开用。
（注：FlClash v3.4 原稿里家宽是留在各组当额外入口的；这一条是站长后来定的新规矩，移植版以新规矩为准。）

## 网速优化做了什么

- **DNS 用国内加密 DNS（DoH）打头**：doh.pub + 阿里 DoH 两个加密解析排前面，解析快、还防运营商污染；后面带 223.5.5.5 / 119.29.29.29 普通 DNS 兜底，DoH 万一抽风也不会断网。（另：`fallback-dns-server` 已不再回落到系统明文 DNS，DoH 失败时解析失败，见配置注释。）
- **直连域名单独走国内 DoH**（direct-dns-server）：国内网站不用绕远路解析，打开更快。
- **fake-ip 兼容名单**（always-real-ip）：游戏联机、语音通话、时间同步、微软连通性检测这些域名返回真实 IP，不会被假 IP 弄坏（和 FlClash 版同一份名单）。
- **劫持硬编码 DNS**（hijack-dns）：有些 App 写死了用 8.8.8.8 解析，强制收回来按规则走，防污染防绕过。
- **测速容差 50 毫秒**：新节点要比当前节点快出 50ms 以上才换线，不会因为一两毫秒的抖动来回跳线，连接更稳。
- **测速超时 3 秒**：测速时坏节点 3 秒就放弃，不拖慢整组出结果的速度。
- **屏蔽走代理的 QUIC**（block-quic = all-proxy）：UDP/443 在很多网络下质量差，屏蔽后自动回退到 TCP 的 HTTP/2，视频和网页反而更稳更快。
- **节点不支持 UDP 就拒绝**（udp-policy-not-supported-behaviour = REJECT）：避免 UDP 流量悄悄绕过代理，既防泄漏也少出怪问题。
- **STUN 返回假地址**（stun-response-ip）：防 WebRTC 把你的真实 IP 漏出去。
- **ICMP 自动回复**：ping 测速类显示更正常。

## 与 FlClash 版的差别（先说清，免得奇怪）

- **地区组里不能逐个挑节点**：FlClash 版地区组是「自动组 + 全部节点」两层，小火箭的分组语法做不到一层里既放自动组又按名字筛节点，所以地区组直接就是自动测速组。想指定某个节点，去「👋 手动选择」里挑。
- **倍率分组是近似**：FlClash 版是程序读节点名里的数字算倍率；小火箭只能用正则认「0.5x」「倍率2」这类写法，写法规矩的订阅没问题，写法太野的可能认不全。还可能误判（比如 `X2Pro` 这类名字会被当成 2 倍率）；倍率分错组只影响省钱策略，不影响连通与安全。
- **没有 UnBan 白名单表**：FlClash 版用的是 ACL4SSR 四件套（带防误杀白名单）；小火箭版改用 blackmatrix7 的广告表（它自家做了防误杀处理），效果接近，来源不同。
- **节点名同时带两个地区词时**：FlClash 版只进先认到的那一个组；小火箭版可能同时进两个组，影响很小（测速会自己选快的）。
- **google.cn / g.cn 会被重写到 google.com**：配置 `[URL Rewrite]` 段有两条（`^https?://(www.)?g.cn` 与 `^https?://(www.)?google.cn`，都 302 到 `https://www.google.com`），国内本可直连的 google.cn 会被改道走代理。这两条规则本身保留（不是误删）；想在国内直连 google.cn，就把配置里这两行删掉。
