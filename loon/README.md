# Loon 包

## 这是什么

- **哪个 APP**：Loon，苹果手机/平板上的代理工具（App Store 付费下载）。
- **文件**：`Loon.conf` —— 一份完整配置，含分流分组、节点筛选器、去广告规则，还预装了一个去广告插件的引用。
- **仓库链接**：`https://gcore.jsdelivr.net/gh/YiMing918/proxy-app-rules@main/loon/Loon.conf`
- **有什么用**：
  - 分流：不同网站/App 自动走不同地区的节点（AI 走美国、YouTube 走香港、国内直连），不用手动切。
  - 去广告：两层——域名规则拦截（不用证书）+ 秋风去广告插件（规则型，也不用证书）。
  - 网速优化：加密 DNS 防污染、SNI 嗅探让分流更准、测速参数调稳（细目见下面）。

## 怎么用（一步一步）

### 1. 先导入你的节点订阅
1. 打开 Loon，底部点「节点」。
2. 点右上角「+」→「订阅」，把订阅链接粘进去，保存并等它更新出节点列表。
   （也可以直接改配置文件 `[Remote Proxy]` 段里那行示例，把链接换成你的再导入配置，二选一即可。）

### 2. 导入这份配置
1. Loon 底部点「设置」→「配置文件」→「添加」，选文件或粘贴链接导入 `Loon.conf`。
2. 导入后在配置文件列表里**点一下这份配置**把它设为当前配置 —— **不点选不生效**。

### 3. 确认插件开着
1. 底部点「插件」，找到「秋风去广告」，确认开关是开的（配置里已预置为启用，没开就手动打开）。

### 4. 选中分组（默认线路已预设好）
1. 底部点「策略组」（或在主页的策略区域），能看到 🤖 AI服务、📺 YouTube 等分组。
2. 每个分组的第一位就是默认线路（见下面表格），平时不用动；想换线路点分组改选即可。

### 5. 要不要装证书（MITM）
- **本配置默认不用装证书**：分流、域名去广告、秋风插件都是按域名拦的。
- 只有装下面那种**分应用深度净化插件**（如知乎助手）时才需要：Loon「设置」→「MITM」→ 生成并安装证书 → 去 iOS「设置 → 通用 → 关于本机 → 证书信任设置」打开信任 → 回 Loon 把 MITM 开关打开，并确认插件开关开着。

### 6. 怎么验证已经生效
1. 主页打开 Loon 开关，点「测速」能测出节点延迟。
2. 打开 ChatGPT：能在「🤖 AI服务」分组里看到它默认走「🇺🇸 美国」，网页能打开就是分流生效。
3. 打开一个开屏广告多的 App，广告被跳过；或在 Loon 的请求日志里看到广告域名被 REJECT，就是去广告生效。

### 7. 以后怎么更新
- 配置：「设置 → 配置文件」里对这份配置下拉/点更新（链接导入时）。
- 里面的远程规则（blackmatrix7 广告表、各服务规则）和插件都是远程引用的，Loon 会按周期自己更新，不用你管。
- 订阅节点：在「节点」页下拉刷新即可。

### 8. 常见问题
- **导入失败**：文件不完整或链接打不开时换个下载方式重试；Loon 配置语法挑剔，别用记事本改过格式再导入。
- **规则不生效**：先查配置有没有被设为「当前配置」；再查主页模式是不是「规则模式」（全局代理/全局直连会绕过分流）。
- **节点不进组（地区组是空的）**：Loon 靠 `[Remote Filter]` 按节点名里的地区词筛选（香港/🇭🇰/HK 都认）。节点名完全不带地区信息的认不出来，去「👋 手动选择」直接挑节点。
- **某个网站打不开**：把「🛑 广告拦截」分组临时改成 DIRECT，能打开就是被去广告误拦了。
- **udp-fallback-mode 不认识**：那是 Loon 3.2.0+ 的字段，旧版会自己忽略，不影响使用，升级到新版即可。

## 两条硬规矩（全套包统一，写在分组表这里）

**规矩一：默认地区没节点，会自动顺位，不会让组空着。**
每个用途组的第一顺位只是「默认」，不是唯一。比如 YouTube 默认香港，但你的订阅里一个香港节点都没有时，这个组不会失效——它默认选的是「📺 YouTube·顺位」兜底链组（Loon 的 fallback 组），顺序是：香港 → 日本 → 新加坡 → 美国 → 台湾 → 韩国 → 其他各地区 → ♻️ 自动选择（压尾）。链上哪个地区有节点就用哪个，只要订阅里还有任何节点，这个组就有得用。其他用途组同理：先走自己的偏好地区（AI 美国打头、流媒体 新加坡→美国），再按 新加坡/美国/台湾/日本/香港/韩国 补位，最后压自动选择。
**但这只是默认行为，没有锁死**：点开任何用途组，所有地区组都列全了，随时能自己改选任何地区组或具体节点。

**规矩二：家宽节点只许手动，绝不自动。**
名字里带「家宽 / 住宅 / 家庭宽带 / Residential」的节点，只出现在「🏠 家宽节点」这一个组里（纯手动选）。所有筛选器（全部节点筛选、各地区筛选）都把家宽词剔除了，所以自动选择、故障转移、负载均衡、每个地区组里都不会有家宽节点，连「👋 手动选择」里都不放（故意的，不是漏了）。
原因：免费家宽上一秒能用、下一秒超时，太不稳定，混进自动组会把测速和自动切换全带乱。需要家宽时，自己去「🏠 家宽节点」里点开用。
（注：FlClash v3.4 原稿里家宽是留在各组当额外入口的；这一条是站长后来定的新规矩，移植版以新规矩为准。）

## 网速优化做了什么

- **加密 DNS（DoH）**：阿里 + 腾讯两个 DoH 一起上，解析快、防污染；普通 DNS（223.5.5.5 / 119.29.29.29）作兜底。
- **SNI 嗅探打开**（sni-sniffing）：有些 App 直接连 IP 不查域名，嗅探能从加密握手里认出它要去哪，分流照样命中，不会误走错线。
- **fake-ip 兼容名单**（real-ip）：苹果/微软连通性检测、游戏联机、语音、网易云等域名返回真实 IP，不被假 IP 弄坏。
- **测速容差 50 毫秒 + 超时 3 秒**：不为一两毫秒抖动频繁跳线；坏节点 3 秒放弃，出结果快。
- **负载均衡用 pcc 算法**：同一网站的连接固定走同一个节点（和 FlClash 版的 consistent-hashing 一个思路），登录类网站不容易掉线。
- **GeoIP 数据库用 Loyalsoldier 维护版**（geoip-url 自动更新）：国内 IP 判断更准，直连/代理分得更对。
- **节点不支持 UDP 就拒绝**（udp-fallback-mode，3.2.0+）：防 UDP 绕过代理。
- **只用 IPv4**（ip-mode = ipv4-only）：和 FlClash 版一致，避开 IPv6 带来的解析绕路和泄漏问题。

## 与 FlClash 版的差别

- **DNS 分流是近似的**：FlClash 版能做到「国外域名走 Cloudflare/Google 的 DoH、国内走国内 DoH」；Loon 的 DNS 不按规则分流，这里统一用国内 DoH（加密、防污染没问题，只是国外域名也用国内 DoH 解析，个别 CDN 定位可能略差一点）。
- **倍率分组是近似**：靠正则认「0.5x」「倍率2」这类写法，写法太野的节点名可能认不全，还可能误判（比如 `X2Pro` 这类名字会被当成 2 倍率）；倍率分错组只影响省钱策略，不影响连通与安全。
- **节点名同时带两个地区词时**可能同时进两个组（FlClash 版只进先认到的一个），影响很小。
- **去广告来源不同**：FlClash 版是 ACL4SSR 四件套；Loon 版是 blackmatrix7 广告表 + 秋风插件，效果接近。
